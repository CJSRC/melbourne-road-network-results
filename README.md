# Melbourne road network from imagery: results by area

The results site of the imagery road-network method (stop-line lanes, direction, mid-block lanes and speed limits read
from Street View and satellite imagery) for six Melbourne areas, set against OSM and the reference data (DTP, council
speed maps, Vicmap, SCATS signal configuration sheets). Open `index.html` (Chinese and English); the map page
`maps/all_areas_results.html` switches between the areas.

Central Melbourne and Footscray still show last week's method; their new run is not finished.
